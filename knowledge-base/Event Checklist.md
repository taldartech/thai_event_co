# Event Checklist

Use these checklists with Process.md. Tick items with clients during planning. Adapt scope for décor-only vs full planning engagements.

---

## Wedding Checklist

### Early planning
- [ ] Vision, cultural requirements, and must-have moments
- [ ] Budget clarity and impact-zone priorities (entrance, ceremony, stage, dining)
- [ ] Guest count and guest profile (elders, international guests, children)
- [ ] Preferred date(s) and backup date if destination
- [ ] Venue shortlist or confirmed venue
- [ ] Colour preferences and inspiration references
- [ ] Ceremony type (Thai traditional, blessing, civil, fusion)
- [ ] Decide: Decor Collective only / Event Collective only / both

### Venue & logistics
- [ ] Site survey (measurements, power, load-in, curfews, fire rules)
- [ ] Photographer positions and backdrop height needs
- [ ] Catering and ceremonial access routes mapped
- [ ] Weather contingency if outdoor
- [ ] Hotel/vendor forms submitted

### Design & production
- [ ] Moodboard / concept presentation
- [ ] Revisions and written approval
- [ ] Quotation approved; deposit paid
- [ ] Floor plans and décor density vs service routes
- [ ] Floral stem counts and tropical mechanics
- [ ] Stage / backdrop drawings
- [ ] Production confirmation and install call sheet
- [ ] Lighting and photographer testing window booked

### Event day
- [ ] Quiet install complete before guests
- [ ] Décor lead on site for adjustments
- [ ] Run-of-show shared with planner/hotel
- [ ] Blessing/ritual pathways clear

### Wrap
- [ ] Dismantling within venue rules
- [ ] Venue returned in excellent condition
- [ ] Optional flower redistribution
- [ ] Debrief / feedback

## Corporate Event Checklist

### Early planning
- [ ] Objectives and success metrics (brand, sales, hospitality, awards)
- [ ] Date, city, and approximate guest count
- [ ] Budget and procurement requirements
- [ ] Stakeholder map (marketing, execs, venue, suppliers)
- [ ] Brand guidelines and logo package received

### Venue & programme
- [ ] Venue sourcing / confirmation
- [ ] Registration or welcome flow
- [ ] Stage / logo / media wall needs
- [ ] VIP protocols and hospitality desk
- [ ] AV rider and technical recon
- [ ] Load-in and breakdown windows

### Design & production
- [ ] Décor concept (if Decor Collective engaged)
- [ ] Branded entrance and gala tables as scoped
- [ ] Run-of-show and cue sheets
- [ ] Supplier briefing before load-in
- [ ] Rehearsal window (awards/keynotes)

### Event day
- [ ] Venue liaison assigned
- [ ] Stage cue manager assigned
- [ ] VIP arrival support
- [ ] On-site issue response path

### Wrap
- [ ] Vendor reconciliation
- [ ] Asset return / dismantle
- [ ] Practical debrief and wrap notes

## Conference Checklist

### Early planning
- [ ] Agenda architecture (plenary, breakouts, hybrid)
- [ ] Audience size and badge/registration needs
- [ ] Speaker list and hospitality requirements
- [ ] Sponsor and exhibition requirements
- [ ] Livestream / recording decision

### Venue & technical
- [ ] Venue capacity and room map
- [ ] Power, internet, rigging, acoustics check
- [ ] Green room / speaker tech checks
- [ ] Registration layout and queue plan
- [ ] Simultaneous session logistics if multi-track

### Production
- [ ] Stage plots and cue sheets
- [ ] AV oversight partners confirmed
- [ ] Sponsor booth coordination
- [ ] Call sheets and radio/comms plan
- [ ] Contingency for overtime / overrun

### Event day
- [ ] Registration open on time
- [ ] Stage management live
- [ ] On-site response team
- [ ] Daily notes for multi-day conferences

### Wrap
- [ ] Wrap reporting
- [ ] Speaker and sponsor thank-you logistics
- [ ] Vendor reconciliation
- [ ] Lessons learned

## Destination Wedding Checklist

### Early planning
- [ ] Vision + budget clarity
- [ ] Destination city (Bangkok, Phuket, Samui, etc.)
- [ ] Multi-day itinerary draft (welcome / ceremony / reception / brunch)
- [ ] Guest count and travel profile (international majority?)
- [ ] Venue shortlist by style and guest count
- [ ] Cultural ceremony segments identified
- [ ] Engage Event Collective and/or Decor Collective

### Remote planning support
- [ ] Structured update cadence for overseas couple
- [ ] Time-zone friendly meetings scheduled
- [ ] Shared folder for floor plans, moodboards, contracts
- [ ] Local vendor shortlist (décor, AV, catering, entertainment)

### Venue & travel logistics
- [ ] Venue contracts reviewed
- [ ] Guest room blocks / welcome notes as scoped
- [ ] Guest transport critical path owner assigned
- [ ] Rehearsal window booked
- [ ] Weather contingency for beach/garden days
- [ ] Freight / island logistics if Samui or remote resort

### Design system
- [ ] Cohesive multi-day décor language
- [ ] Day-by-day décor install plan
- [ ] Floral plan for heat/humidity
- [ ] Photo moments mapped per event

### Production calendar
- [ ] Production confirmation milestone
- [ ] Crew travel booked
- [ ] Load-in per venue access rules
- [ ] Day-of command roles (venue liaison, cues, VIP)

### Wrap
- [ ] Multi-venue dismantle schedule
- [ ] Final vendor payments reconciliation
- [ ] Couple debrief
- [ ] Optional media / thank-you coordination

## Quick shared critical path (all event types)

Assign an owner to each:
- [ ] Venue confirmation  
- [ ] Technical riders  
- [ ] Guest transport (if any)  
- [ ] Rehearsal windows  
- [ ] Permits (activations)  
- [ ] Weather contingency  
- [ ] Supplier briefing before load-in  
- [ ] Breakdown / venue return
